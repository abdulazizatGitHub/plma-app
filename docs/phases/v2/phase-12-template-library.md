# v2 Phase 12 — Public template library

**Release:** R4 · **Requirements:** LIB-01…05 (unchanged from Addendum A) · **Depends on:** 3

## Goal

Users publish their own category templates. Others can adopt and star them.

## Scope

The rules and open questions in the archived [phase-14-template-library](../archive/phase-14-template-library.md) carry over unchanged. They now apply to categories and items instead of habits. Provenance columns have existed since Phase 1.

## Acceptance

- [ ] Publishing fails if any item's provenance points to another author's template (LIB-04).
- [ ] Adopt, star, and sort-by-stars all work.
