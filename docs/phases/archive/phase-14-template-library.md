# Phase 14 — Public Template Library (later)

## Goal

Addendum A3 (LIB-01…05): users share templates publicly. Others adopt and star them, like a repository.

## Rules (from owner, 2026-09-30)

1. **Publish own only.** A user may make public only a template they authored (LIB-01).
2. **Browse, adopt, star.** Public templates are discoverable; stars rank them (LIB-02).
3. **Extend alongside, not inside.** An adopter can add their own extra goals, habits, and tasks next to an adopted template. The adopted template's items stay as published (LIB-03).
4. **No re-publishing adopted work.** An adopter cannot add items to someone else's template and publish the result as their own template. This is treated as cheating (LIB-04). Enforce it server-side: publishing fails if any item's provenance points to another author's template.
5. **Provenance is permanent.** The source template, author, version, and adoption time are stored on every adopted item, starting in Phase 06B (LIB-05).
