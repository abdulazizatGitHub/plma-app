# Phase 08 — Daily Tasks, Weekly & Monthly Goals

## Goal

CRD §11–13: dated custom tasks (description, reminder, EOD summary); weekly goals with deadline; monthly goals with target/actual/remaining (e.g. Rs. savings).

## Acceptance criteria

- [ ] Task list per day with completion and end-of-day summary
- [ ] Weekly goal review at week end
- [ ] Monthly goal progress bar (target/saved/remaining)
